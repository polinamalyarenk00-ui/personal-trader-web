# Личный трейдер Web 1.0

Русскоязычное учебное приложение: графики, новости, Gemini, анализ рисков и виртуальный портфель. Нет реальных или автоматических сделок.

## Запуск

Streamlit Community Cloud: этот репозиторий, ветка `main`, файл `app.py`, Python 3.12. Без ключей работает деморежим с синтетическими ценами и шаблонным помощником.

Локально: `pip install -r requirements.txt`, затем `streamlit run app.py`.

## Реальные данные

Добавьте только в Streamlit App settings → Secrets:

```toml
ALPACA_API_KEY = ""
ALPACA_SECRET_KEY = ""
GEMINI_API_KEY = ""
GEMINI_MODEL = "gemini-3.1-flash-lite"
```

Никогда не коммитьте реальные ключи. Выберите «Рынок · Alpaca IEX» в интерфейсе. Бесплатность зависит от квоты, региона и тарифа аккаунта. Приложение не определяет тариф; не подключайте платный биллинг для бесплатного сценария.

## Ограничения

Портфель и чат изолированы по браузерным сессиям, без постоянных аккаунтов. Перед закрытием сохраняйте портфель в JSON; обновление страницы и перезапуск сервера могут удалить сессию. Демо и рыночные портфели разделены.

Alpaca: дневные IEX-свечи до конца предыдущих суток UTC, не текущие цены всего рынка. Новости за последние 7 дней, до конца предыдущих суток. Проверяйте права на распространение рыночных данных перед публичным использованием.

Ответы ИИ могут содержать ошибки; наличие идентификатора источника не доказывает вывод. В Gemini отправляются вопрос, краткая история диалога и рыночный контекст, но не портфель автоматически. Не вводите личные сведения; бесплатный Gemini может использовать запросы для улучшения продуктов.

## Проверка

`pip install -r requirements-dev.txt`, затем `python -m pytest -q`.

46 тестов: расчёты, импорт, API-ошибки, лимиты, источники и изоляция сессий. Действительные вызовы API требуют ключей владельца. Код разделён на `app.py`, `core.py`, `services.py`; тесты лежат рядом.
